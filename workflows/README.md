# Workflows

Contiene los procesos oficiales de trabajo definidos por WIKA.

Los workflows describen cómo se crea, revisa, aprueba y publica un proyecto.

Todo proceso operativo debe encontrarse documentado en esta carpeta.

process-engine.md                 # Máquina de estados (Studio / validate)
