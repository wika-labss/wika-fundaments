# Templates

Contiene las plantillas oficiales utilizadas por WIKA.

Las plantillas permiten mantener consistencia documental entre proyectos y entregables.

Todo documento generado dentro de WIKA debe basarse en una plantilla oficial cuando exista.

## Plantillas oficiales

```text
01-problem.md
02-features.md
03-module-discovery.md
04-application-design.md
05-build-plan.md
```

Estas plantillas se copian a `applications/<proyecto>/idea/` durante la etapa de Preparación.
