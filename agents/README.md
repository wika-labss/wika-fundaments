# Agents

Contiene la definición de los agentes IA que participan dentro de WIKA.

Cada agente posee responsabilidades específicas, reglas de operación y límites claramente definidos.

Los agentes colaboran para generar, revisar y evolucionar proyectos.

El catálogo nominativo de agentes (nombre, inputs, outputs y límites) está pendiente de formalización; ver `ROADMAP.md`. Hasta entonces, todo agente que opere sobre un proyecto WIKA debe respetar `.cursorrules`, `templates/` y `docs/`.
