# Contributing — wika-studio

1. Reglas SCOS y gates viven en [`wika-fundaments`](https://github.com/wika-labss/wika-fundaments); no duplicar plantillas 01–05 aquí.
2. Cambios de API deben alinearse con `docs/studio-api-contract.md` en fundaments (PR allí primero si el contrato cambia).
3. Ejecutar `npm run typecheck` antes de PR.
4. UI no activa flags YAML; solo rol arquitecto aprueba gates.
5. Arranque Windows: [`docs/windows-runbook.md`](docs/windows-runbook.md).
