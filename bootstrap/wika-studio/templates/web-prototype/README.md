# Prototipo web (WIKA)

Iteración `prototype/` creada por WIKA Studio a partir de `templates/web-prototype`.

- Alcance: demo navegable para iterar con el cliente. No es release.
- Reglas: tokens en `src/theme.ts` (sin hex sueltos en pantallas); lógica pura en `src/engine/` sin React.
- Scripts (contrato `iteration-environment-spec.md`): `npm run dev` (imprime `PREVIEW_URL=`), `npm run verify`, `npm run build:artifact`.
- Imágenes del cliente: `assets/`.
